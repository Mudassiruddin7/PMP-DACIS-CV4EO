\section{Limitations}
\label{sec:limits}

\num{resisc45:seeds} class partitions are few. The spread over partitions in the tables mixes how hard a partition is with training noise, and it is itself estimated from five numbers. Every hyper-parameter, including $\lambda$, was fixed in advance and shared by all scores. The one value we tuned, the episodic learning rate, was tuned on the dense network and on PlantVillage validation classes, then reused on the Earth-observation sets; a score or a stage that needs its own learning rate or recovery schedule did not get its best case. \numif{repl:mad}{Hardware adds noise of its own: rerunning the same code and seeds on an \num{repl:gpu} instead of the main GPU changed the accuracy of a single run by \num{repl:mad} points on average and by up to \num{repl:max} points over \num{repl:n} runs, so a difference of about one point between two single runs is within that noise.}

``Novel'' means novel with respect to the base classes, not with respect to pre-training: the ImageNet initialisation has seen photographs of airplanes, ships, tennis courts and other concepts that reappear among the novel RESISC45 classes. The Earth-observation results cover two classification benchmarks of single-label patches. EuroSAT-MS has ten classes, which allows a $5/5$ class split and nothing larger, so its novel-class numbers rest on a five-class base set. RESISC45 is RGB. No model uses coordinates, acquisition dates, synthetic-aperture radar or any sensor beyond the thirteen optical bands, and none was tested on full scenes or on time series, so what is specific to \emph{geospatial} data is absent from this study. PlantVillage images are leaves on a plain background, and the dataset holds several photographs of the same leaf. We did not use leaf identities to keep support and query images apart, so near-duplicates can raise the PlantVillage numbers; the PlantDoc, RESISC45 and EuroSAT-MS results do not depend on that. PlantDoc here is a cropped-leaf release with one dropped class, and its concepts overlap those of PlantVillage.

Cost is reported as parameters, multiply-accumulates, and latency on one server CPU and one GPU. We did not run on a Raspberry Pi, a Jetson or an accelerator on board a satellite, and we measured no energy, so we say nothing about those devices. Only ResNet-18 and only the inner convolution of each residual block were pruned. Quantisation, distillation, architecture search and recent few-shot learners were not compared; the claims are limited to channel scores and training schedules inside this one design.

What we can and cannot conclude. The paired intervals over five partitions are wide, so a null result means ``not distinguishable at about \num{cmp:halfw:PMP} points'', not ``equal''. Each partition has one training run per method, so training noise and method effect are confounded inside a partition, and the $28$ comparisons share their random baseline and their partitions and are not independent. The episodic stage was tested with one recipe (frozen BatchNorm, at most the smallest learning rate of the grid, $1000$ episodes, $5$-way $5$-shot). The compact networks were trained with a recipe set for the ResNet and were not pruned, so the comparison with the pruned ResNet-18 is not at equal effort, and we did not try satellite-pretrained backbones. RESISC45 scenes were resized from $256$ to $128$ pixels, which changes the ground sampling distance, and the class-disjoint split does not separate neighbouring tiles geographically. The Sentinel-2 comparison between thirteen and three bands depends on how the first convolution was initialised.
